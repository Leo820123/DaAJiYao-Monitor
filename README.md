# 大A纪要 · Windows 图形界面监控器

固定监控 https://www.bilibili.com/opus/1219141791464292387 的当前置顶一级评论，及其楼中楼里 **UP 主本人**（按 UID 识别）的回复。不抓取其他普通用户评论作为结果。

## Windows EXE 下载与使用

1. 打开 [Actions → Build Windows EXE](../../actions/workflows/build-windows.yml)，选择最新成功的运行，在 Artifacts 中下载 `DaAJiYaoMonitor-Windows`。
2. 解压并双击 `DaAJiYaoMonitor.exe`。**不需要安装 Python**，但需要本机安装 Chrome 或 Edge。
3. 点击「登录并启动监控」。弹出的浏览器需要登录具有充电动态访问权限的 B 站账号。程序获取访问权限后会关闭登录浏览器并自动开始监控；网络请求通过本地登录会话进行。
4. **首次启动会自动补抓当前置顶评论内已经发表的所有可访问楼中楼回复**，只保存 UP 主本人回复。界面显示补抓进度、遍历数量、UP 主匹配数和本次新增保存数；本地保存 SQLite 数据库及 CSV 文件。
5. 任何时候都可点击 **「补抓当前置顶的历史回复」** 重新扫描，自动去重，历史补抓不弹通知。
6. 默认每 120 秒检查一次。可以设置检查间隔（30–3600 秒）。

## 通知和老板键

- 「发现 UP 主新回复时弹窗提醒」**默认关闭**。关闭时完全不弹抓取通知，记录仅保存在软件主界面与本地文件中。打开窗口后才能查看。
- 如果主动打开提醒开关，只有软件可见时，识别到本次新增的 UP 主回复才弹窗。首次及手动历史补抓不触发弹窗提醒。
- **全局老板键默认为 `Ctrl+Alt+H`**，可在设置中改为 `Ctrl+Shift+Z`、`Alt+Q`、`F9` 配合修饰键等。按一次隐藏窗口并关闭正在显示的提醒；后台继续检查和记录。再按一次恢复窗口。
- 「软件启动时隐藏窗口」为可选设置。
- 即使开启了提醒，**软件隐藏期间绝不弹出抓取提醒**；恢复窗口后可查看期间记录。
- 关闭主窗口仅隐藏，不退出。使用「退出程序」结束进程。

## 重要限制

- 尚未使用具备充电权限的账号实测评论 API 与置顶结构。B 站接口、登录权限、限流等可能造成抓取失败；请以界面状态和实际记录为准。
- 登录过程会显示独立浏览器，**登录时不要使用老板键期待能隐藏该浏览器**；老板键隐藏的是监控软件窗口。完成登录后浏览器会自动关闭。
- 老板键的组合键必须有 Ctrl/Alt/Shift/Win 等修饰键，防止与日常输入冲突。若被其他软件占用，软件会显示错误。
- 请勿把 `browser_profile/`、`settings.json`、`history.sqlite3`、`monitor.log` 或登录信息上传到 GitHub。
- 可补抓**当前仍然置顶**的主评论下已发表、接口仍可访问的旧回复；无法保证恢复启动前**已经取消置顶**且未保存过的历史主评论，也无法恢复已删除、无权限或接口不返回的回复。
- 旧版 EXE 的本地 `history.sqlite3` 可以继续使用：新 EXE 放在旧 EXE 所在目录以沿用数据库及配置。**先备份原有文件夹**，避免覆盖本地历史。
